# Third party sources

The PPO collection, GAE and clipped actor/critic update structure, separate ELU
MLPs, orthogonal initialization and KL learning-rate adaptation follow
[Catch It](https://github.com/hang0610/Catch_It), commit
`b6af28c67586fc029f3ab43faf5d787e7d3a1609` (MIT, see LICENSE.catch_it).

The release/flight/landing task organization follows
[catch_it_throw](https://github.com/Winstongh/catch_it_throw), commit
`9146768e5a592858d5e19378e9e1b24a0c2d3b43` (MIT).
This implementation removes catching and mobile-base components, adds object
and goal conditioning, uses one-time release rewards and actual first-contact
landing metrics, and fixes timeout bootstrapping and bounded evaluation.
Its checkpoints are not compatible with the upstream mobile/dexterous-hand policies.

The unmodified xArm7/native UFACTORY gripper MJCF and STL assets are from
[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie/tree/f3b6013629c7b94f8ee93fd977b161fa8350f9bc/ufactory_xarm7),
commit `f3b6013629c7b94f8ee93fd977b161fa8350f9bc` (BSD-3-Clause).
The license and Git blob hashes are bundled with the assets. Native robot joint
ranges, actuator gains, force ranges, friction and gripper linkage are retained.
Scene/object/freejoint/landing-plane additions are generated by env.py in memory.

## 视频动作参考

新增 `assets/motions/mit_overhand.json` 是对 [MIT UAN 项目公开投掷视频](https://uan.csail.mit.edu/) 的六个关键帧所作人工二维关键点标注，以及数据来源、视频 SHA256 和不确定性说明。原视频没有随软件分发。xArm7 参考关节角是本项目根据投影方向拟合的一组 IK 解，不是源机器人的实测关节数据。

模仿目标与任务目标联合训练的思路参考 [DeepMimic](https://xbpeng.github.io/projects/DeepMimic/)，本次没有复制其代码；显式投影姿态奖励、示教采集和 BC/PPO 实验由本模块实现。
